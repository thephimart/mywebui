# WebUI (Fully Specified)

## Layout

```
┌ Sidebar (Sessions / Docs / Settings) ─┐
|                                      |
|              Chat Area               |
|                                      |
└── Input Bar (attach, STT, send) ─────┘
```

## Features

- Light / dark mode
- Streaming responses
- Drag-drop attachments
- Session list (search, pin, export, compact)
- Docs panel (categories, ACL indicators)
- Inspector panel:
  - active model
  - tools enabled
  - docs selected
  - token usage
